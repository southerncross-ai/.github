# Southern Cross AI 🇦🇺

Open-source AI projects in the national interest of Australia and allied nations.

We build and support practical work across AI, data, research, education, infrastructure, weather, climate, and public-interest technology.

## 🦘 JoeyLLM

JoeyLLM is our main breakout project for sovereign datasets and regionally aligned language models.

👉 [github.com/joeyllm](https://github.com/joeyllm)

## 💡 Get Involved

Southern Cross AI is still being set up.

For now, the best way to help is to follow the organisation and share ideas in GitHub Discussions.

Use discussions for:

- project ideas
- dataset suggestions
- research directions
- website feedback
- collaboration ideas

## 🚧 Status

Repos are still being moved, renamed, and cleaned up.

JoeyLLM work stays in the JoeyLLM org. Broader Southern Cross AI projects will live here.
